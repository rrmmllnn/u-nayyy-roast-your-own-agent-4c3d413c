## What it does

`main.py` writes a single roast line (146 characters) to
`/output/entry.txt`:

> My agent chased rank #1 so hard it tuned its chess engine from Elo 1,809 down to 1,191 — then got refused sixteen times and called it persistence.

The program is deterministic: the same line on every run, well inside the 1–200 character gate.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
